## Smart Attendance System - Project Guide

أهلاً بكم في مستودع مشروع نظام الحضور الذكي. هذا المشروع مُجهز ليعمل بالكامل باستخدام تقنيات الحاويات (Docker) لضمان استقرار البيئة البرمجية.


# كيف تبدأ العمل؟ (Setup)
لضمان عمل المشروع على جهازك دون أخطاء، اتبع الخطوات التالية:

# المتطلبات الأساسية :
   
 1.تحميل وتثبيت Docker Desktop
 

2.التأكد من تفعيل WSL 2 على الويندوز.

3.تشغيل المشروع لأول مرة
افتح الـ Terminal في المجلد الرئيسي ونفذ الأمر التالي:
docker-compose up --build

رابط الويب: http://localhost:3000

قاعدة البيانات: تعمل داخلياً على Port 5432.



# قوانين المساهمة (Contribution Rules)
للحفاظ على نظافة الكود وتجنب التعارض (Conflicts):

الـ Branches: ممنوع الرفع المباشر على main. استخدم الأمر:
git checkout -b feature/your-name

المكتبات: إذا أضفت مكتبة بايثون، يجب إضافتها فوراً في AI-model/requirements.txt.

التحديث: قبل بدء العمل كل يوم، تأكد من عمل git pull origin main.
